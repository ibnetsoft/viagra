# 공지와 기기 알림

관리자 `/admin`의 **공지 관리**에서 제목·내용·수신 대상을 입력합니다. 정상 회원 전체 또는 최대 500명의 회원을 선택할 수 있습니다. 임시 저장은 발송하지 않습니다. **저장하고 발송 미리보기 → 발송 확정**을 누르면 해당 시점의 대상 회원에게 공지가 등록됩니다. 발송한 공지는 수정할 수 없습니다.

회원은 앱 상단 종 모양의 **알림함**에서 공지를 확인합니다. 읽지 않은 개수가 표시되며, 개별 공지를 열거나 모두 읽음을 누르면 읽음 상태가 저장됩니다. 앱이 열린 동안 30초 간격과 창을 다시 열 때 갱신됩니다. 발송 후 새로 가입한 회원에게 과거 전체 공지가 자동 배정되지는 않습니다.

회원 알림함에서 **이 기기 알림 켜기**를 누르고 브라우저 알림을 허용하면 기기 푸시도 수신합니다. 아이폰은 iOS 16.4 이상에서 Safari의 공유 메뉴로 홈 화면에 추가한 앱을 열어 허용합니다. 각 기기에서 별도로 설정합니다. 푸시를 거부해도 앱 알림함은 이용할 수 있습니다. 잠금 화면에는 공지 도착 안내만 표시하며 공지 본문은 로그인 후 확인합니다.

관리자 공지 내역은 수신 회원 수, 읽은 회원 수, 푸시 접수 기기 수, 대기 및 미전송 기기 수를 표시합니다. 푸시 접수는 브라우저 푸시 서비스가 요청을 받아들였다는 의미이며 실제 화면 표시나 읽음을 보장하지 않습니다.

## 서버 설정

- 서버 전용 환경변수: `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`, `SUPABASE_SERVICE_ROLE_KEY`, `PUSH_CRON_SECRET`. 실제 값은 저장소에 넣지 않습니다.
- `20260910124944_announcements_and_push.sql`을 적용하고 `enable-push-scheduler.sql`을 실행합니다. Vault의 `vital_push_cron_secret`은 Vercel의 `PUSH_CRON_SECRET`과 일치해야 합니다.
- 발송 직후 전송을 시도하고 Supabase의 `vital-push-dispatch` 작업이 매분 미처리 작업을 확인합니다. 작업이 없으면 Vercel 호출을 하지 않습니다.
- 일시 오류는 최대 5회, 최대 24시간 재시도합니다. 유효하지 않은 구독은 비활성화합니다. 기기 알림 끄기 및 로그아웃 시 해당 기기의 구독과 대기 작업을 해제합니다.
- VAPID 키를 교체하면 기기 재등록이 필요하므로 배포할 때마다 키를 새로 만들지 않습니다.

## 검증 범위

권한·수신 대상·임시 저장·발송 중복 방지·읽음 상태·대기 작업 재선점·구독 취소는 격리된 데이터베이스에서 검증합니다. 푸시 암호화와 서비스 워커 표시·클릭, 전송 성공·만료·재시도 처리는 격리된 테스트로 검증합니다. 모바일 화면은 브라우저에서 확인합니다. 실제 휴대폰 수신은 해당 기기에서 알림을 허용한 뒤 확인해야 합니다. 운영 회원에게 테스트 공지를 일괄 발송하지 않습니다.
