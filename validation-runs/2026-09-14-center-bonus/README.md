# 센터 보너스 변경 검증 (2026-09-14)

- 센터 3%, 센터장 직접 추천인 2%. 신규 구매 당시 소속/추천 관계를 고정하여 한국 시간 익일 00:01 일일 정산.
- 두 보너스는 150만원 한도 검사/차감에서 제외. 회원 정지 정책은 유지.
- 추천인 없는 2%는 관리자 전용 센터장추천미지급 원장에 기록. 나중에 추천인을 지정해도 과거 기록 자동 지급 없음.
- 입금/PV 충전은 매출 보너스를 발생시키지 않으며 실제 PV 상품 구매가 기준.
- 통합 테스트 21개 통과. 최종 변경 후 센터/구매 테스트 3개 및 프로덕션 빌드 통과.
- 한도 소진 회원, 최초/반복 구매, 추천인 변경, 누락 추천인, 재요청, 일일 재정산, 관리자 전용 조회/쓰기 차단 검증.
- 테스트 예: 센터 900,000 PV → 센터장 27,000원, 추천인 있는 600,000 PV → 추천인 12,000원, 추천인 없는 300,000 PV → 미지급 6,000원.
- 운영 DB 변경 전 보너스 0건 확인. 기존 구매/회원/지급 데이터 유지. 신규 구매부터 적용.
- 운영 DB RLS 및 함수/테이블 권한 직접 검증. 변경 전 함수 백업은 로컬 functions-before.sql에 보존.
